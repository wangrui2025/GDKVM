# Website maintenance

For website work, start with [website/DEVELOPMENT.md](website/DEVELOPMENT.md) and the local design
specification it links. Reuse the existing Astro source, token system, tests,
and Pages deployment. Preserve publication facts, source provenance, paper
assets and localized content; do not reinterpret example commands or model
results. Inspect the current branch and open PRs, validate the changed layer,
and report exact candidate and actual serving state separately.

Before changes to product direction or site IA, read [current website Wish](docs/wish/LATEST.md) and [Wish interpretation](docs/wish/DESIGN.md). Preserve the paper, experiment-code, website design and Dev authorities.
